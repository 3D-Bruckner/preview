# preview v0.2, step 1: the look — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** The customer pages and the web app take the mock's look: a theme switch (Auto/Hell/Dunkel), one shared header, the overview as model cards, and the model page as a viewer beside a side panel.

**Architecture:** Presentation only: no schema, backend or REST change. The theme is a cookie set by a plain form POST like the language (`/api/theme`), read by the root layout into `data-theme` on `<html>`; `globals.css` keys its dark values on that attribute and on the system preference when it is `auto`. The pages keep reading `customerView` / `customerModel` as today.

**Tech Stack:** Next.js (App Router), Tailwind v4 (`app/globals.css` `@theme`), Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-27-preview-v0.2-design.md` (Goal 1, "The look", "The customer pages"). The mock: `/root/3D-Bruckner/preview-designs/Open Design/vorschau-app/vorschau-app.html` (published: https://claude.ai/artifact/5MwmYhva2nbXAEEA7HSVMK). Plates, parts, measurements, view buttons, figures and feedback are later steps: leave no placeholders for them.

## Global Constraints

- `CLAUDE.md`'s rules hold: no literal text in JSX (`react/jsx-no-literals`), every new word in `components/copy/en.ts` and `de.ts` (same keys), the product names no operator, `npm run format:check`, `lint`, `typecheck`, `test`, `test:e2e` and `generate -- --check` green.
- Palette and fonts stay as they are in `app/globals.css` (they already are the design's: `--bg #ffffff`, `--surface #f5f5f6`, `--fg #15171c`, `--muted #5a606c`, `--border #e2e4e9`, dark `#0f1115/#181b21/#f0eee9/#a6a9b1/#2b2f38`; Hanken Grotesk text, Archivo headings). The accent stays `PREVIEW_ACCENT_COLOR`.
- Radii: 6 px for cards, buttons, inputs and tiles (`rounded-md`); pills stay `rounded-full`. No shadows except the focus ring.
- Accent use on a customer screen: the logo (the operator's own file) and at most one primary action.
- The customer pages set no cookie unless the visitor uses the language or the theme switch.
- Widths: customer pages `max-w-[1240px]`, gutters as today (`px-safe`, 2rem from `md`); the web app keeps `max-w-3xl`.

## Review Focus

- A visitor with JavaScript off: both switches still work (plain forms, 303 back to the page).
- `Auto` with a dark system: the dark palette applies without a flash of light (the attribute is set on the server; `auto` sets none and the media query decides).
- A model with a single version and no drawings: the side panel shows only "Versionen", no empty card.
- A long model title or customer name on a 390 px phone: the header and the breadcrumb wrap or truncate, nothing overflows sideways.
- A tampered `preview_theme` cookie (`neon`): treated as `auto`, no error.
