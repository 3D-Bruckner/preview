# preview v0.3: plan

Design: [2026-11-28-preview-v0.3-design.md](../specs/2026-11-28-preview-v0.3-design.md). One branch, `v0.3`, one pull request; each
task a commit, `npm run typecheck && npm run lint && npm test` green after each.

1. **Views.** Migration `views` (`customers.seen_at`, `version_views`), store queries, `backend/views.ts` (`recordView`, starts from

4. **Icons and flags.** New icons in `components/icons.tsx`; `LanguageSwitch` as flags (`components/flags.tsx`); adding-a-language doc.

7. **Model (admin).** Breadcrumb, title + edit dialog, the two buttons, version cards with picture, seen and inline feedback, the
   upload beside them.
8. **Customer model page.** Multi-select focus (scene `focus(keys)`), focus bar, parts list rows (tint, dim, ×/focus, compact
   picker, scroll), Maße + Druck under the view, sticky side panel with the Rückmeldung, "Neu in Version n", no Versionen card,
